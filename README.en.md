# Percent Calculator

A modern web-based percent calculator with an animated background, support for multiple measurement units (₽, $, €, kg, g, m, km, pcs, l) and language switching (RU/EN).

## Features

- Calculate percentages in both directions (percent of a number and vice versa)
- 9 measurement units to choose from
- Bilingual interface (Russian / English)
- Beautiful animated background with particles and gradients
- Responsive design for mobile devices
- Fully client-side — no backend required

## Tech Stack

- HTML5
- CSS3 (animations, gradients, responsive)
- Vanilla JavaScript
- Google Fonts (Inter)

## Running Locally

Just open `index.html` in any modern browser:

```bash
open index.html
```

Or start a simple local server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Deployment

The project is hosted via **GitHub Pages** and requires no build step — it's a single static HTML file.
